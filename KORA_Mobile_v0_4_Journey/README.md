# KORA Mobile v0.4 — Journey Prototype

Private single-user prototype. No account, cloud backend, payment system or paid API required.

## Adds
- Single-player Journey prototype: The Glass March
- Permanent Growth from training, movement and fueling
- No decay, streak loss or punishment
- Fixed-body avatar with cosmetic/style progression only
- Exploration nodes and locked map progression
- Turn-based encounters and first boss: Warden of the Pass
- Permanent cosmetic artifacts
- Workout completion automatically banks daily Training Growth
- Test buttons simulate future Apple Health/Yazio inputs for steps and nutrition

## Deliberate prototype simplifications
- Art is procedural/vector-style placeholder art to validate mechanics first.
- Steps and nutrition are manual claims until Health integration is implemented.
- Combat balance is intentionally simple.
- Single player only; no server or multiplayer.

Commercial-ready principle: game state, workout logic and external program content remain separate modules.
